Arty, à portée de main

Un accès direct.
Sur votre appareil.

Utilisez Arty dans le navigateur, ajoutez son icône à votre écran d’accueil, ou accédez à la bêta Android si vous avez une invitation.

Déjà utilisateur ? Conservez votre ancien espace.

Une nouvelle installation ou une connexion au même compte ne transfère pas automatiquement les conversations et fichiers locaux. Conservez l’ancienne application et ses données.

L’ancien domaine, un autre navigateur ou profil, la version web installée et l’APK Android peuvent avoir des espaces distincts. Deux icônes Arty ne garantissent pas les mêmes données. La restauration et la synchronisation entre appareils ne sont pas disponibles.

Avant le menu d’installation, ouvrez la page d’accueil d’Arty dans le navigateur choisi. N’installez pas cette page de guide.

Version web installée · PWA

Android avec Chrome

  1. Dans Chrome, allez sur tryarty.com.
  2. Ouvrez le menu à trois points et cherchez l’option d’installation, parfois dans « Installer et créer un raccourci ».
  3. Choisissez « Installer », puis confirmez dans la fenêtre du navigateur. Ouvrez ensuite l’icône Arty.

Les intitulés varient selon la version de Chrome. Si l’option manque, vous pouvez continuer dans le navigateur.

Version web installée · PWA

iPhone et iPad avec Safari

  1. Dans Safari, allez sur tryarty.com.
  2. Ouvrez le partage de la page, directement ou via le menu Plus. Cherchez « Sur l’écran d’accueil », éventuellement sous Plus.
  3. Si proposé, activez « Ouvrir comme app web », puis validez l’ajout. Ouvrez ensuite l’icône Arty sur l’écran d’accueil.

La présentation varie selon iOS ou iPadOS. Si l’action manque dans le partage, consultez les instructions Apple correspondant à votre appareil.

Version web installée · PWA

Ordinateur avec Chrome

  1. Dans Chrome, allez sur tryarty.com.
  2. Utilisez l’icône d’installation près de l’adresse si elle apparaît, ou cherchez l’installation dans le menu de partage et d’enregistrement de Chrome.
  3. Confirmez l’installation proposée par le navigateur, puis ouvrez Arty depuis vos applications.

Sans option d’installation, Arty reste accessible dans un onglet. Les autres navigateurs peuvent proposer un menu différent.

Application Android native · sur invitation

Bêta APK avec Firebase

Cette voie est réservée aux testeurs invités. Ce guide ne fournit pas de téléchargement APK public ni de lien Google Play.

  1. Sur Android, ouvrez votre invitation Firebase App Distribution et acceptez-la avec un compte Google.
  2. Retrouvez Arty dans le portail de testeurs avec le compte utilisé pour accepter l’invitation. Il peut être différent de votre compte Arty.
  3. Suivez les instructions de téléchargement et d’installation Firebase. L’application App Tester est facultative.

Sans invitation, ou si Arty n’apparaît pas, contactez l’assistance. L’accès n’est pas automatique.

Mes conversations ou mon abonnement semblent manquer

Vérifiez l’adresse du site, le navigateur ou profil utilisé et le compte affiché dans Arty. L’installation seule ne restaure ni les données locales ni un droit VIP. Ne désinstallez pas votre ancienne application et n’effacez pas ses données pour essayer de les récupérer. Contactez l’assistance en décrivant le support et le problème, sans mot de passe ni contenu privé.

La version web et l’APK font-ils exactement la même chose ?

Non. La version web installée utilise le navigateur ; l’APK est l’application Android native. Certaines fonctions diffèrent : la connexion mail IMAP est réservée à Android natif. Installer une version ne convertit pas l’autre et ne partage pas automatiquement son espace local.

Puis-je utiliser Arty sans connexion internet ?

Les réponses IA et les services Google nécessitent internet. Certains éléments déjà chargés peuvent rester visibles, mais cela ne garantit pas le fonctionnement complet hors ligne. Si ce guide est indisponible hors ligne, rétablissez le réseau puis rechargez la page.

Je ne trouve pas le menu d’installation

Ouvrez directement tryarty.com dans Chrome ou Safari, hors du navigateur intégré à une autre application. L’installation dépend du navigateur et de l’appareil ; elle peut aussi avoir déjà été faite. Vous pouvez utiliser Arty dans un onglet sans modifier votre installation existante.
